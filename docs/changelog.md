# CGMMgr CHANGELOG

## 2026-06-08 작업기록 탭 변경
- 작업기록 탭을 사용자 입력용 메모 화면이 아니라 프로그램 변경내역 표시 화면으로 전환했습니다.
- `docs/CHANGELOG.md` 파일을 기준 소스로 추가했습니다.
- 앱에서 `docs/CHANGELOG.md`를 읽어 변경 목록을 같은 내용으로 표시하도록 연결했습니다.
- 작업기록 탭에 새로고침 상태 표시를 추가했습니다.

## 2026-06-08 작업기록 탭 추가
- 상단 내비게이션에 작업기록 탭을 추가했습니다.
- 작업기록 화면과 목록 UI를 앱에 추가했습니다.
- 로컬 저장 구조와 백업/복원 데이터에 작업기록 상태를 포함하도록 확장했습니다.

## 2026-06-08 재고 운영 보완
- 재고 상세에서 삭제 기능을 추가해 중복 등록 데이터를 완전히 제거할 수 있게 했습니다.
- 센서 종류 설정을 화면에서 수정할 수 있게 변경했습니다.
- 재고 목록과 대시보드에서 유효기간 중심으로 보이도록 구성을 단순화했습니다.

## 2026-06-08 GS1 및 DataMatrix 보강
- GS1 compact 문자열 파싱을 보완해 GTIN, 유효기간, LOT, 일련번호 매핑을 강화했습니다.
- 센서별 스캔 프로파일 분리 구조를 적용해 CareSens, 바로잰, Dexcom 경로를 나눴습니다.
- 이미지 스캔 결과를 GS1 원문 입력에 자동 반영하도록 연결했습니다.
